# FlixBridge contributor entry point

Read [AGENTS.md](AGENTS.md) for repository instructions and the actual source before changing a contract. Use [architecture](docs/architecture.md), [configuration](docs/configuration.md) and the [tool reference](docs/api-reference.md) for current implementation details; do not infer modules from old plans.

For tool operations follow [RULE.md](RULE.md) and the [public skills](skills/README.md). Default to inspection; previews and confirmation tokens are not mutation authority. Keep private credentials, hosts, maintenance profiles and operational logs out of Git.

For local checks and publication boundaries see [contributing](.github/CONTRIBUTING.md) and [CI](.github/workflows/README.md). Verification does not publish a release.
